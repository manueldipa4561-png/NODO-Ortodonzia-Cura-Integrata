# NODO — Ortodonzia / Cura Integrata

Fictional premium orthodontic and integrated-care website concept created for the Punto Due Studio portfolio.

## Concept

NODO treats orthodontics as a relationship between alignment, function, structure and surface. The digital experience is designed around clarity, calm and precise explanation rather than conventional dental marketing.

**Core line:** _Mettere in relazione prima di allineare._

## Signature interaction

**Architettura del sorriso / Relationship Field** is an original four-layer interaction derived from a Higgsfield 3D Jutsu art-direction study. The production website uses a dependency-light inline SVG system with meaningful phase controls:

1. Allineamento
2. Funzione
3. Struttura
4. Superficie

The SVG exists in the HTML before JavaScript runs, so the section never degrades into an empty stage. JavaScript only enhances phase state and drag orientation. Reduced-motion users receive the static composition.
